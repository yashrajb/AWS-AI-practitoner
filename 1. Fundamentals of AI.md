# Artificial Intelligence — Detailed Notes

## 1. Fundamentals of Artificial Intelligence

### 1.1 What is Artificial Intelligence (AI)?

* **Artificial Intelligence (AI)** is the broad field of building computer systems that can perform tasks that normally require **human-like intelligence**.
* These tasks can include:

  * Understanding language
  * Recognizing images
  * Making predictions
  * Reasoning and decision-making
  * Learning from experience/data
  * Generating text, images, audio, or code
  * Planning and problem-solving

**Simple example:**

A system that can look at a photograph and identify whether it contains a dog is an AI system.

Another example is a chatbot that understands your question and generates an appropriate response.

> **Important:** AI does not necessarily mean machine learning. An AI system can also be built using explicitly programmed rules.

For example:

```text
IF temperature > 40°C
THEN display "Extreme Heat Warning"
```

This is an AI-like decision system, but it does **not learn from data**.

## 2. AI vs Machine Learning vs Deep Learning

These concepts are hierarchical:

```text
Artificial Intelligence
│
├── Rule-based AI
│
└── Machine Learning
    │
    ├── Traditional ML
    │
    └── Deep Learning
        │
        └── Neural Networks
```

### 2.1 Artificial Intelligence

* **AI is the broadest category.**
* Its goal is to make machines perform tasks requiring intelligence.
* It can use:

  * Rules
  * Search algorithms
  * Logic
  * Machine learning
  * Neural networks
  * Other computational techniques

### 2.2 Machine Learning (ML)

* **Machine Learning is a subset of AI.**
* Instead of explicitly programming every rule, we provide **data** and allow the system to learn patterns from that data.

For example, instead of writing:

```text
IF email contains "WIN MONEY"
THEN spam
```

we could give an ML model thousands of examples:

```text
Email 1 → Spam
Email 2 → Not Spam
Email 3 → Spam
...
```

The model learns patterns associated with spam.

### 2.3 Deep Learning

* **Deep Learning is a specialized subset of ML.**
* It uses neural networks with **multiple layers**.
* Deep learning is particularly effective for:

  * Images
  * Speech
  * Natural language
  * Video
  * Complex pattern recognition

Examples include systems used for:

* Image recognition
* Speech recognition
* Large language models
* Autonomous driving

### 2.4 Neural Networks

* Neural networks are computational models loosely inspired by the structure of biological brains.
* They contain interconnected computational units called **neurons/nodes**.
* These nodes are organized into layers:

```text
Input Layer → Hidden Layers → Output Layer
```

For example, an image classification model might receive:

```text
Image pixels
     ↓
Neural network
     ↓
Features
     ↓
Prediction
     ↓
"Cat"
```

The "deep" in deep learning generally refers to having multiple layers between the input and output.

# 5. Model vs Algorithm

These two terms are extremely important.

## 5.1 Algorithm

An **algorithm** is a defined procedure for solving a problem.

Think of it as a **recipe**.

Example:

```text
1. Take two numbers
2. Compare them
3. Return the larger number
```

That's an algorithm.

In ML, examples include:

* Linear regression
* Decision trees
* K-means
* Gradient descent
* Neural-network training algorithms

## 5.2 Model

A **model** is the learned mathematical representation produced after applying a learning process to data.

Think:

```text
Algorithm + Training Data
          ↓
       Trained Model
          ↓
       Predictions
```

Example:

```text
Training data:
House size + bedrooms + location + price

        ↓
   ML algorithm

        ↓
Trained model

        ↓
Predict price of new house
```

### Easy analogy

* **Algorithm = recipe**
* **Training data = ingredients**
* **Model = finished dish**
* **Inference = using the finished dish**

# 6. Training

**Training** is the process of teaching an ML/AI model using data.

During training:

```text
Training Data
      ↓
   Model
      ↓
Prediction
      ↓
Compare with expected result
      ↓
Calculate error
      ↓
Adjust model parameters
      ↓
Repeat
```

The goal is generally to minimize some measure of error/loss.

### Example

Suppose we want to recognize cats.

Training data:

```text
Image 1 → Cat
Image 2 → Dog
Image 3 → Cat
Image 4 → Dog
```

The model makes predictions.

If it predicts:

```text
Actual: Cat
Predicted: Dog
```

there is an error.

The training process adjusts the model's parameters so that it can make better predictions.

### Important distinction

**Training is computationally expensive.**

Once a model is trained, using it to make predictions is called **inference**.

# 7. Inference / Inferencing

**Inference** is the process of using a trained model to produce predictions or outputs for new input data.

```text
New Input
    ↓
Trained Model
    ↓
Prediction / Output
```

Example:

```text
User:
"What is the capital of France?"

       ↓

LLM

       ↓

"Paris"
```

The model is performing inference.

### Training vs inference

| Training                                     | Inference                           |
| -------------------------------------------- | ----------------------------------- |
| Teaches the model                            | Uses the trained model              |
| Uses training data                           | Uses new input                      |
| Usually expensive                            | Usually cheaper                     |
| Happens during model development/fine-tuning | Happens when application is running |

For an application developer, this distinction is very important because **production AI applications are primarily concerned with inference**.

# 8. Bias

**Bias** refers to systematic errors or tendencies in an AI system that can cause consistently inaccurate or unfair outcomes.

Bias can enter an AI system through:

* Training data
* Data collection
* Labels
* Model design
* Human decisions
* Deployment environment

### Example

Suppose a hiring model is trained on historical hiring data that contains discriminatory patterns.

The model may learn those patterns and reproduce them.

Therefore:

```text
Bad / biased historical data
          ↓
       ML model
          ↓
Potentially biased predictions
```

### Important point

AI models don't automatically become unbiased simply because they are mathematical.

The quality and representativeness of the data matter enormously.

---

# 9. Fairness

**Fairness** is concerned with making sure AI systems do not systematically disadvantage particular groups.

For example, if an AI system is used to evaluate loan applications, developers need to consider whether its predictions unfairly disadvantage certain demographic groups.

Fairness can involve:

* Checking model performance across groups
* Detecting discriminatory patterns
* Evaluating training data
* Monitoring production behavior
* Applying appropriate safeguards

### Bias vs fairness

* **Bias:** systematic tendency/error in the system.
* **Fairness:** whether outcomes and treatment are equitable across relevant groups.

These are related but not exactly the same concept.

# 10. Model Fit

**Fit** describes how well a model represents or performs on data.

Three important concepts are:

### Underfitting

The model is too simple.

```text
Model → Doesn't learn enough
```

It performs poorly even on training data.

### Good fit

The model learns useful patterns without simply memorizing the training data.

### Overfitting

The model learns the training data too closely, including noise.

```text
Training performance → Very good
New/unseen data → Poor
```

This is why we generally evaluate models using **unseen/test data**.

### Generalization

A good ML model should **generalize**: it should perform well on new data rather than only the examples it saw during training.

# 11. Large Language Models (LLMs)

**Large Language Models (LLMs)** are AI models designed to process and generate human language.

Examples of tasks:

* Answering questions
* Summarization
* Translation
* Code generation
* Text generation
* Information extraction
* Classification
* Conversational interaction

Modern LLMs are generally based on **transformer architectures**.

A simplified view:

```text
User Input
    ↓
Tokens
    ↓
LLM
    ↓
Generated Tokens
    ↓
Text Response
```

### What is a token?

An LLM generally doesn't process an entire sentence as one indivisible unit.

Text is converted into **tokens**, which may represent:

* Words
* Parts of words
* Characters/symbols in some cases

For example:

```text
"I love programming"
        ↓
     Tokens
        ↓
      Model
```

### Important distinction

An LLM is a **model**, not an algorithm.

The model has learned statistical patterns from its training process and uses those learned parameters during inference.

# 12. Types of Inferencing

There are two important categories mentioned in the video:

## 12.1 Batch Inferencing

Batch inference means processing **multiple inputs together**.

Example:

Suppose an e-commerce company wants to generate recommendations for 10 million customers every night.

Instead of processing customers individually in real time:

```text
Customer 1
Customer 2
Customer 3
...
Customer 10M
       ↓
Batch processing
       ↓
Recommendations
```

This is suitable when results don't need to be immediately available.

### Typical use cases

* Nightly reports
* Data processing
* Customer segmentation
* Generating embeddings for large datasets
* Bulk document processing
* Fraud analysis performed periodically

### Advantages

* Efficient for large amounts of data
* Can optimize compute utilization
* Often cheaper than real-time processing

### Disadvantage

Results are not immediately available.

---

# 13. Real-Time Inference

Real-time inference processes an input and produces a response with low latency.

Example:

```text
User sends message
       ↓
AI model
       ↓
Response
```

The user expects the response immediately.

### Examples

* Chatbots
* Fraud detection during a transaction
* Autonomous vehicles
* Voice assistants
* Real-time recommendation systems
* Face/object detection in live video

### Important concept: Latency

**Latency** is the time between receiving an input and producing the required response.

For real-time applications:

```text
Lower latency → Better user experience
```

For example, a chatbot that takes 30 seconds to respond to every simple request may provide a poor user experience.

---

# 14. Batch vs Real-Time Inference

| Feature             | Batch                   | Real-Time                        |
| ------------------- | ----------------------- | -------------------------------- |
| Inputs              | Many at once            | Usually individual/request-based |
| Response            | Delayed                 | Immediate/low latency            |
| Cost efficiency     | Usually high            | Can be more expensive            |
| Latency requirement | Low                     | High                             |
| Example             | Nightly recommendations | Chatbot                          |
| Priority            | Throughput              | Latency                          |

### Key terms

* **Latency:** How quickly one request gets a response.
* **Throughput:** How many requests/data points can be processed over a period of time.

A system may optimize for one or both depending on the application.

# 16. Unlabeled Data

Data that does not have predefined outcomes/labels.

Example:

```text
Customer records

Customer A
Customer B
Customer C
...
```

There is no label saying which customers belong to which category.

Unlabeled data is commonly used in approaches such as **unsupervised learning**.

For example, clustering can discover groups in the data:

```text

    ↓

    ↓
Group A
```

* Supervised learning
* Unsupervised learning
* Self-supervised learning
* Reinforcement learning

**Self-supervised learning** is particularly important for modern LLMs because models can learn from large amounts of raw data by creating training signals from the data itself.

# 29. Quick Interview/Exam Definitions

* **AI:** The broad field of creating systems capable of performing tasks associated with human intelligence.
* **Machine Learning:** A subset of AI where systems learn patterns from data.
* **Deep Learning:** A subset of ML that uses multi-layer neural networks.
* **Neural Network:** A computational model composed of interconnected processing units organized into layers.
* **Model:** A learned mathematical representation used to make predictions or generate outputs.
* **Algorithm:** A procedure or set of steps for solving a problem.
* **Training:** The process of learning model parameters from data.
* **Inference:** Using a trained model to generate predictions or outputs.
* **Bias:** A systematic tendency or error that can produce inaccurate or inequitable outcomes.
* **Fairness:** The goal of ensuring AI systems produce equitable treatment/outcomes for relevant groups.
* **LLM:** A large AI model specialized in processing and generating human language.
* **Batch inference:** Processing many inputs together, usually when immediate results aren't required.
* **Real-time inference:** Processing inputs with low latency when rapid responses are required.
* **Labeled data:** Data accompanied by known target outcomes.
* **Unlabeled data:** Data without predefined target outcomes.
* **Structured data:** Data organized according to a predefined schema.
* **Unstructured data:** Data such as text, images, audio, and video that doesn't naturally follow a fixed tabular schema.
* **Overfitting:** When a model learns training data too closely and performs poorly on unseen data.
* **Underfitting:** When a model is too simple to adequately learn the underlying patterns.
* **Generalization:** The ability of a model to perform well on new, unseen data.

### The most important mental model

If you're learning AI as a **software engineer rather than an AI researcher**, don't try to memorize every mathematical detail at this stage. Make sure you can clearly understand this chain:

**Data → Algorithm → Training → Model → Inference → Application Output**

And understand that **AI application development is usually about integrating these models into real software systems**, rather than building the underlying models from scratch.
