# What is Reinforcement Learning?

Reinforcement Learning (RL) is a Machine Learning technique where a system learns by:

```text
Taking Actions
        ↓
Observing Results
        ↓
Getting Rewards/Penalties
        ↓
Improving Future Decisions
```

Unlike Supervised Learning:

```text
Input → Correct Answer
```

RL does NOT start with correct answers.

The model learns through experience.

---

# Reinforcement Learning vs Other ML Types

---

# Supervised Learning

## Learns From Labeled Data

Example:

| Image | Label |
|---------|---------|
| Car Image | Car |
| Dog Image | Dog |

Model learns using correct answers.

---

## Example Use Cases

- Image Classification
- Spam Detection
- Price Prediction

---

# Unsupervised Learning

## Learns Without Labels

Finds hidden patterns.

---

### Example

Customer Data:

```text
Group A = Premium Customers

Group B = Budget Customers
```

---

# Reinforcement Learning

## Learns Through Rewards

No labels provided.

The model discovers the best strategy itself.

---

## Example

```text
Robot Learns Walking
```

through trial and error.

---

# Easy Comparison

| Type | Learns From |
|--------|--------|
| Supervised Learning | Correct Answers |

# Limitations of Reinforcement Learning

## Requires Many Iterations

Training may require:

```text
Thousands
Millions
Even Billions
```

of attempts.

---

## Reward Design is Difficult

Bad rewards create bad behavior.

Example:

```text
Reward = Speed Only
```

Car might learn:

```text
Drive Fast
Ignore Safety
```

---

## Real-World Testing Can Be Expensive

Training a real car on roads would be costly and risky.

Therefore:

```text
Simulations are commonly used.
```

# Common RL Algorithms

You do NOT need deep mathematical knowledge for most foundational exams.

Just know their purpose.

---

## Monte Carlo

Learns from complete episodes.

Example:

```text
Play Entire Game
↓
Analyze Results
↓
Learn
```

---

## Q-Learning

Learns:

```text
Which action gives
the highest future reward.
```

Very popular RL algorithm.

---

## DQN (Deep Q Network)

Combines:

```text
Neural Networks
+
Q-Learning
```

Used for more complex environments.

---

## PPO (Proximal Policy Optimization)

One of the most widely used modern RL algorithms.

Popular because it:

- Learns efficiently
- Is relatively stable
- Works well for robotics and games

### One-Line Interview Answer

> **Reinforcement Learning is a machine learning technique where an agent learns optimal behavior through trial and error by interacting with an environment, taking actions, observing outcomes, and receiving rewards or penalties. Over many episodes, the agent learns which actions maximize long-term rewards and achieve a desired goal.**
