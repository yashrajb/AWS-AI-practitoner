# What is Amazon SageMaker AI?

Amazon SageMaker AI is a **fully managed Machine Learning service** that helps developers, data scientists, business analysts, and ML engineers build, train, deploy, and monitor machine learning models.

### In Simple Terms

Without SageMaker:

```text
Collect Data
↓
Setup Servers
↓
Install ML Tools
↓
Configure Infrastructure
↓
Train Model
↓
Deploy Model
↓
Monitor Model
```

Lots of manual work.

---

With SageMaker:

```text
Collect Data
↓
Build Model
↓
Train
↓
Deploy
↓
Monitor
```

AWS manages most of the infrastructure.

# Model Monitoring

A deployed model must be monitored continuously.

---

## What SageMaker Monitors

### Model Quality

Checks:

- Accuracy
- Prediction errors
- Performance degradation

---

### Bias Detection

Detects if predictions become unfair.

Example:

```text
Loan Model

Male Approval = 85%
Female Approval = 60%
```

Potential bias issue detected.

---

### Drift Detection

## What is Drift?

Drift occurs when production data changes significantly from training data.

---

### Example

Training Data:

```text
Average Purchase = $100
```

Production Data:

```text
Average Purchase = $500
```

Model performance may decrease.

---

### Automatic Detection

SageMaker can identify:

```text
Data Drift
Model Drift
Bias Drift
```

and notify teams.

---

# Artifact Tracking

## What is an Artifact?

Anything produced during ML development.

Examples:

- Model files
- Training datasets
- Evaluation reports
- Code versions
- Experiment results

---

## Why Track Artifacts?

Suppose a model fails.

Teams need to know:

```text
Which model?
Which dataset?
Which code?
Which experiment?
```

Artifact tracking provides traceability.
